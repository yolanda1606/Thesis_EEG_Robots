Setting up communication

Step 1. Connect physically via ethernet the Laptop and the PC 
Step 2. Set up IP addressby running:
    ip addr
    sudo ip addr add 10.0.0.1/24 dev enp71s0
    sudo ip link set enp71s0 up
Step 3. Verify last setp with:
    ip addr show enp71s0
Step 4. Set up IP address on windows Laptop 
    - WIndows key + R type control
    - Click on Netzwerk un Internet
    - Click on Netzwerk und Freigabecenter
    - Click on Ethernet 2
    - Click on Eigenschaften
    - Click on Internetprotokol Version 4 (TCP/IPv4)
    - Set IP-Adresse to 10.0.0.2
    - Set Sunetymaske 255.255.255.0
    -click okay
Step 5 Run the listener on the Laptop
Step 6 Test communication by running on the PC
    echo "test_trigger" | nc -u -w1 10.0.0.2 1000
    (If you see Received trigger on the Laptop, connection was successfull)

Go back sudo ip addr del 10.0.0.1/24 dev enp71s0
