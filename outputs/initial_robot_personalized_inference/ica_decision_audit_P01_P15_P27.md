# ICA decision audit: P01, P15, and P27

## Decision

**Do not retain ICA as a required final-methodology step on the evidence presently available.** The matched Robot transfer results do not show a consistent ICA advantage, and the archive contains no matched ICA-versus-no-ICA Image cross-validation experiment from which to claim an accuracy benefit. The scientifically defensible status is **INCONCLUSIVE**, with no-ICA preferable provisionally for parsimony only if the methodology explicitly records that the final choice still needs a matched Image-CV confirmation.

Robot ratings below are post-hoc descriptive validation only. They were not used for any selection or decision rule.

## Provenance and inventory

Current matched artifacts used: P01 `ica_inference_v3` / `no_ica_inference_v3`; P15 `v2` / `v2`; P27 `v2` / `v2`. Older versions were not pooled. The window-key pairing check passed for every pair. Face-only models are negative controls: their features and predictions cannot change under EEG ICA, so their identical shift warnings do not constitute ICA evidence.

- P01: v3; targets valence/arousal; six tasks; ICA/no-ICA have identical model-window keys (1,802 matched model-windows), with task-specific matched model-window entries: pick_place=218, shape_sorter_alone=85, shape_sorter_interaction=453, shape_sorter_observation=333, sisyphus=323, stack=390. Per-model valid-window counts are shown in the task table and CSV.
- P15: v2; targets valence/arousal; six tasks; ICA/no-ICA have identical model-window keys (2,277 matched model-windows), with task-specific matched model-window entries: pick_place=125, shape_sorter_alone=83, shape_sorter_interaction=485, shape_sorter_observation=628, sisyphus=582, stack=374. Per-model valid-window counts are shown in the task table and CSV.
- P27: v2; targets valence/arousal; six tasks; ICA/no-ICA have identical model-window keys (2,379 matched model-windows), with task-specific matched model-window entries: pick_place=228, shape_sorter_alone=123, shape_sorter_interaction=546, shape_sorter_observation=339, sisyphus=741, stack=402. Per-model valid-window counts are shown in the task table and CSV.

The implemented shift warning is exactly: **median nearest Image-training distance > 10.0**, measured in the final model’s selected, standardized feature space. It is not triggered by a z-score threshold or an outside-range threshold. The pipeline computes all diagnostics only in selected dimensions; it does not save a formal per-feature attribution, so the feature entries in the warning table are descriptive standardized-distance contributors, not independent warning rules.

## Cross-participant transfer pattern

Among EEG/multimodal models only (excluding invariant face controls), pooled mean selected-space distance was ICA=11.854, no-ICA=5.441; outside-value fraction ICA=10.6%, no-ICA=7.6%; median |z| ICA=0.862, no-ICA=0.791. ## Final scientific interpretation

1. **Does ICA improve Image classification accuracy consistently?** No conclusion is possible: matched ICA/no-ICA Image-CV results are not present. Shared deployment models cannot establish an ICA accuracy effect.

2. **Are any ICA accuracy gains large enough relative to CV variability?** Not assessable. P01’s stored outer-CV SD is reported above for its selected models, but there is no matched no-ICA counterpart. P15/P27 do not retain outer-CV variability in this export.

3. **Which preprocessing generally produces smaller Image→Robot feature shift?** Neither consistently. The pooled affected-model means lean no-ICA for distance/outside range only if the values above do so, but individual target/task/model diagnostics are mixed; invariant face-model warnings are identical by design. This is insufficient evidence that ICA should remain mandatory.

## Required confirmation before a final locked preprocessing decision

Run a strictly matched Image-only ICA versus no-ICA cross-validation audit for P01/P15/P27: identical trials, labels, folds, feature families, model grid, and selection protocol; report paired fold deltas and their variability. Robot ratings must remain excluded from that audit.
